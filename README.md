# Cafeteria Website

## Tech stack

- Angular 21 with server-side rendering
- TypeScript 5.9
- Tailwind CSS 4
- Angular Reactive Forms
- RxJS
- Lucide Angular icons
- ngx-toastr notifications

## Installation

```powershell
cd "C:\Parallel Universe\AP Caferteria\Repositories\apcafeteria-website"
npm install
```

## Running

Start the Flask backend on port `8000`, then run:

```powershell
npm start
```

Open `http://127.0.0.1:5175`.
